# Recipe Site（レシピサイト／レシピページ） [3周目]

CODEJUMP 入門編の「レシピサイト／レシピページ」課題として制作しているWebサイトです。（基礎固めの3周目）

## 概要

「友達から依頼されたレシピサイトの個別レシピページを制作する」という架空の案件設定のもと、下層Webページ（1ページ）を制作しています。
トップページとリンクで繋ぎ、サイト全体としての整合性を意識してコーディングを行います。

CODEJUMPの課題を通して、レスポンシブな画像表示、リストの点線装飾、相対値（%）を用いた余白設計について学習しています。

## コーディング仕様・学習内容

- **フォント指定**: `Helvetica Neue`, `Arial`, `Hiragino Sans`, `Meiryo`, `sans-serif`
- **コンテンツ幅**: 全幅表示（100%）
- **メイン画像**:
  - 高さ 700px 固定、画面サイズに応じて拡大・縮小
- **テキスト・コンテンツエリア**:
  - テキストエリアの横余白は 5% に設定
  - 材料と作り方のリストは点線で区切り配置
- **一覧ボタン・フッター**:
  - トップページと共通の仕様・SNSリンクの配置
- **レスポンシブ対応**:
  - ブレークポイント 834px
- **Git / GitHub**: バージョン管理

## 使用技術

- HTML5
- CSS3
- Git / GitHub
